# Diabetic Readmission Prediction Pipeline

This project builds an end-to-end data pipeline for hospital diabetic readmission prediction. It includes ETL, data quality checks, feature engineering, model training, and inference.

## Project structure

- `etl_pipeline.py` - extracts CSV data, cleans it, merges datasets, and loads into `diabetic_db.sqlite` as `diabetic_records`
- `data_quality.py` - validates the database table, checks nulls, type consistency, and detects outliers
- `feature_engineering.py` - transforms `diabetic_records` into `ml_ready_features` with categorical encodings and engineered columns
- `train_model.py` - trains machine learning models on `ml_ready_features`, selects the best model, and saves `best_readmission_model.joblib`
- `predict.py` - loads the saved model and predicts readmission for sample rows
- `run_pipeline.py` - executes the full sequence: ETL → quality → feature engineering → training
- `diabetic_db.sqlite` - project SQLite database
- `model_report.txt` - model evaluation report generated by training
- `data_quality_report.txt` - data quality report generated by validation

## How to run

1. Open a terminal in this folder.
2. Run the full pipeline:
   ```powershell
   python .\run_pipeline.py
   ```
3. After the pipeline finishes, run inference:
   ```powershell
   python .\predict.py --limit 3
   ```

## Output files

- `best_readmission_model.joblib` - trained model artifact
- `model_report.txt` - training and evaluation metrics
- `data_quality_report.txt` - dataset health summary
- `run_pipeline.log` - pipeline execution log
